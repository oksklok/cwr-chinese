# Translation conventions

The Chinese-only master in `distribution/payload.json` is authoritative.
Simplified text was translated from current Remastered English; Traditional
text was reviewed for Taiwan usage. Historical Chinese localization is not a
wording source. Preserve keys, ordered rows, stock columns, placeholders,
HTML attributes, marker links, literal line breaks and canonical identities.

Use Chinese-only geographic names in visible prose, including islands and
places without built-in map labels. Internal world names, marker IDs and link
targets remain stock. Nová Ves and Velka Ves are distinct source locations;
do not reconcile their different uses in Hostages by changing the plot.
The terrain overlay contains 18 Everon, 14 Malden and 30 Nogova labels.
Kolgujev has no stock town labels; do not invent terrain entries.

Character spellings include 戴维·阿姆斯特朗, 詹姆斯·加斯托夫斯基,
罗伯特·哈默, 山姆·尼科尔斯 and 维克托·特罗斯卡.
Traditional forms include 大衛·阿姆斯壯, 詹姆斯·加斯托夫斯基,
羅伯特·哈默, 山姆·尼科爾斯 and 維克多·特羅斯卡.
Keep semantic callsigns such as 熊爸爸、黑熊、白狼、鹰眼.
The canonical identity `Victor Troska` stays untranslated.

Functional formations use A小队/B小队, B组 and A排/Y排/Z排 as context
requires; tank formations can use B坦克分队. Aircraft use N编队,
N一号/N二号/N长机; individual calls use A一号 or Y三号.
Radio codes use 代号 A or A：0-0-1, without inventing formations.
Traditional equivalents retain the same letters and compact spacing.

Keep Latin weapon/model designations and distinguish the M60 machine gun
from the M60 tank. Simplified uses 弹匣; Taiwan usage includes 彈匣,
戰車/反戰車, 飛彈, 砲兵/機砲, 導引 and 雷射.
Taiwan UI uses 選單/設定/預設, 儲存/讀取, 檔案/資料夾,
滑鼠, 伺服器/網路/區域網路/頻寬/埠, 螢幕 and 任務精靈.
Use 計畫 and 「」/『』 where appropriate. Preserve contextual terminology
already reviewed in the master; these notes are not instructions to retranslate it.
