CWRC — 免费社区汉化 / Free community Chinese translation

适用于 / Requires Windows x64 Cold War Assault Remastered 3.05.

1. 将 ZIP 解压到 Remastered 目录（原版 PoseidonGame.exe 所在目录）。
   Extract into Remastered, alongside the original PoseidonGame.exe.
2. 双击 CWRC.cmd。首次运行会读取游戏资源，在 @CWRC 内生成汉化覆盖文件。
   Run CWRC.cmd. First launch prepares local overlays inside @CWRC.
3. 在 Options > Game > Language 选择 ChineseSimplified 或 ChineseTraditional。
   Select Simplified or Traditional Chinese in Options > Game > Language.
   其他已选模组保留；语音保持英语。可在游戏内切换语言。
   Other selected mods are retained; voices stay English. Language can be changed in game.
4. 移除：关闭游戏，删除 @CWRC、CWRC.cmd 和本文件。
   Remove: close the game and delete @CWRC, CWRC.cmd and README-CWRC.txt.
   原版游戏文件不变。存档和用户设置仍由游戏管理。
   Original files are unchanged. The game continues to manage profiles and saves.

Preparation reads required 3.05 data only. If it reports an incompatible source,
restore that file through your game provider. Unrelated mods/files are ignored.
To prepare again, delete @CWRC/prepared.txt and run CWRC.cmd.
If a Visual C++ runtime DLL is missing, install Microsoft's x64 Visual C++ 2022 runtime.
An older experimental CWRC installer must first be removed with its own uninstaller.

Do not share the prepared @CWRC folder: it contains copies derived from your game.
Share only the original ZIP. This is an unofficial, noncommercial community mod.
